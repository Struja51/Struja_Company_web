# Struja Company

## Project Description
Struja Company is a web-based platform designed to provide users with information and services related to energy solutions. The website features a modern design that reflects the company's branding and values.

## Project Structure
The project consists of the following files and directories:

- **assets/logo.svg**: The logo for Struja Company, designed using the main colors extracted from the provided image.
- **css/styles.css**: Contains styles for the web page, including layout, typography, and color schemes that align with the branding of Struja Company.
- **js/main.js**: JavaScript code for handling interactivity and dynamic content on the web page.
- **index.html**: The main HTML document that includes the structure of the page, links to the CSS and JavaScript files, and references the logo.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser to view the Struja Company website.
